# LiftLog — Web Engineering Midterm Project

LiftLog is a responsive client-side web application built with HTML, CSS, JavaScript, Bootstrap 5, and Chart.js. It allows users to manage their workout logs, view summary statistics, analyze activity distribution via interactive charts, and secure their sessions using local storage and SHA-256 password hashing.

## Features
- **User Authentication:** Client-side registration, login, session management (`sessionStorage`), and secure password hashing.
- **Protected Routing:** Prevents unauthenticated users from accessing the dashboard.
- **CRUD Operations:** Add, delete, and toggle completion status for daily workout records.
- **Search & Filter:** Instantly filter workout entries by title or category.
- **Data Visualization:** Interactive charts powered by Chart.js.
- **Fully Responsive:** Designed with Bootstrap 5 grid layout for mobile and desktop viewports.
